# 成本估算

## 免费额度汇总

| 服务 | 免费额度 | 超出费用 |
|---|---|---|
| **Cloudflare Workers** | 10万次请求/天 | $5/月起，含1000万次/月 |
| **Cloudflare R2** | 10GB 存储 + 100万 A 类/月 + 1000万 B 类/月 | 存储 $0.015/GB/月，A 类 $4.5/百万 |
| **Cloudflare D1** | 5GB 存储 + 500万读/天 + 10万写/天 | $0.75/GB/月 |
| **Cloudflare CDN** | 无限带宽 | $0 |
| **Vercel Hobby** | 100GB 带宽/月 | $20/月起 |
| **域名** | — | ~$10/年 |

> 简化后不再使用 KV，全部元数据走 D1。

## 场景估算

### 场景一：小型项目（日请求 1 万）

假设：
- 日请求 10,000 次
- 缓存命中率 90%
- 平均文件大小 500KB
- 月存储增长 2GB

| 项目 | 用量 | 费用 |
|---|---|---|
| Workers | 30万/月 | $0 |
| R2 存储 | 2GB | $0 |
| R2 B 类（命中 R2） | ~90万/月 | $0 |
| R2 A 类（回源写入） | ~30万/月 | $0 |
| D1 | 少量读写 | $0 |
| Vercel | 前端访问 | $0 |
| **总计** | | **$0/月** |

### 场景二：中型项目（日请求 10 万）

假设：
- 日请求 100,000 次（达到 Workers 免费上限）
- 缓存命中率 85%
- 平均文件大小 1MB
- 月存储增长 15GB

| 项目 | 用量 | 费用 |
|---|---|---|
| Workers | 300万/月 | $0（未超免费日限额累计？需确认） |
| R2 存储 | 15GB（超 5GB） | ~$0.08 |
| R2 A 类（回源写入） | ~450万/月（超 350万） | ~$15.75 |
| Vercel | 前端访问 | $0-20 |
| **总计** | | **约 $16-36/月** |

> 注意：Workers 免费额度是按天计算（10万/天），不是按月累计。如果某天超过 10 万，超出部分会被限制或计费。

### 场景三：大型项目（日请求 100 万）

| 项目 | 用量 | 费用 |
|---|---|---|
| Workers Paid | 3000万/月 | $5 + $6 = $11 |
| R2 存储 | 100GB（超 90GB） | $1.35 |
| R2 A 类 | 大量写入 | 视情况而定 |
| Vercel Pro | 可能超出 | $20/月起 |
| **总计** | | **约 $32+/月** |

## 成本优化建议

1. **提高缓存命中率**
   - 合理的 TTL（7-30 天）
   - 热点资源预热
   - 稳定的缓存键（避免 query string 穿透）

2. **减少 R2 A 类操作**
   - 批量预热，避免频繁小文件写入
   - 对不常变的资源设置更长的 TTL
   - 使用 R2 生命周期规则清理过期文件

3. **减少 D1 写入**
   - 不记录单条访问日志
   - 统计信息按天聚合，每天只更新一行
   - 源站配置变更不频繁，写入量可控

4. **控制 Vercel 带宽**
   - 管理后台不要放大量静态资源
   - 使用图片优化和压缩
   - 必要时将前端迁移到 Cloudflare Pages

5. **Workers 额度管理**
   - 监控每日请求量
   - 接近 10 万/天时考虑升级 Paid 或加边缘缓存

## 备选低成本方案

| 国内轻量服务器 + Nginx 缓存 | ~$3-5/月 | 低 |
| Cloudflare Pages + Functions 部分代理 | $0 | 中 |
